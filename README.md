# Calculator Trick (PITATA-style deception) — SwiftUI iOS app

Нативное iOS-приложение (SwiftUI), повторяющее фокус с калькулятором:
рабочий калькулятор → тап по центру экрана «ломает» его и кнопки
осыпаются → наклоном телефона (гироскоп) их можно катать, тряской —
восстановить → деление на текущий год «читает мысли» и превращается в
слово **МОНТАЖ** → свайп вверх раскрывает, что всё это время была просто
фотография — и она реально сохраняется в вашу галерею.

## Требования

- macOS с Xcode 15 или новее
- iOS 16+ (гироскоп/акселерометр и определение встряхивания работают
  только на настоящем iPhone — в симуляторе tilt/shake не сработают,
  но остальной интерфейс проверить можно)

## У меня только Windows — как собрать без Mac?

Xcode существует только под macOS — это ограничение Apple, обойти его
локально на Windows нельзя. Но собрать приложение всё равно можно, без
покупки Mac:

### Вариант A — GitHub Actions (бесплатно, автоматически)

В проекте уже лежит `.github/workflows/build-ipa.yml`. После того как вы
запушите репозиторий на GitHub (см. раздел «Публикация на GitHub» ниже):

1. На GitHub откройте вкладку **Actions** в репозитории.
2. Запустите workflow **Build unsigned IPA** (кнопка *Run workflow*),
   либо он запустится сам при пуше в `main`.
3. Через пару минут в разделе **Artifacts** появится
   `CalculatorTrick-unsigned-ipa` — скачайте его, внутри `.ipa`-файл.
4. Для публичных репозиториев такие сборки на GitHub бесплатны без
   ограничений; для приватных — в рамках бесплатной квоты минут в месяц.

Файл будет **неподписанным** — сама Apple не даёт подписывать
приложения без Mac, это следующий шаг:

### Вариант B — установка .ipa на iPhone прямо с Windows

1. Установите **Sideloadly** (sideloadly.io) — бесплатная программа для
   Windows.
2. Подключите iPhone по USB, откройте Sideloadly.
3. Перетащите скачанный `CalculatorTrick-unsigned.ipa` в окно.
4. Введите свой обычный Apple ID (бесплатный, покупать ничего не нужно)
   — Sideloadly сам подпишет и установит приложение на телефон.
5. На iPhone: `Настройки → Основные → VPN и управление устройством` →
   доверьтесь профилю разработчика с вашим Apple ID.
6. Ограничение бесплатного Apple ID: приложение перестанет
   запускаться через 7 дней, нужно будет переустановить тем же
   способом ещё раз (это ограничение Apple, а не Sideloadly).

Разрешения на гироскоп и сохранение в Фото при этом запросятся у вас
точно так же, как у любого обычного приложения из App Store.

### Вариант C — облачный Mac

Если нужен полноценный Xcode с интерфейсом (например, чтобы
подправить код или добавить иконку), можно на пару часов арендовать
облачный Mac — например, MacinCloud или MacStadium (около $1/час) —
и открыть в нём этот же проект как обычно.

## Запуск (если у вас есть Mac)

1. Откройте `CalculatorTrick.xcodeproj` в Xcode.
2. Подключите iPhone, выберите его как target устройства.
3. В `Signing & Capabilities` выберите свою команду (Team) для подписи —
   это нужно один раз, Xcode сделает это автоматически при первом запуске.
4. Нажмите ▶ Run.

## Разрешения, которые запрашивает приложение

- **Motion & Fitness / гироскоп** (`NSMotionUsageDescription`) — чтобы
  катать «осыпавшиеся» кнопки наклоном телефона и ловить встряхивание.
- **Доступ к Фото на добавление** (`NSPhotoLibraryAddUsageDescription`) —
  чтобы в конце реально сохранить кадр фокуса в галерею пользователя.

Оба запроса появляются в системном диалоге iOS в момент первого
использования соответствующей функции — не при запуске приложения.

## Структура проекта

```
CalculatorTrick/
├── CalculatorTrick.xcodeproj/       # проект Xcode
└── CalculatorTrick/
    ├── CalculatorTrickApp.swift     # точка входа
    ├── ContentView.swift            # весь UI и логика фокуса
    ├── MotionManager.swift          # обёртка над CoreMotion (гироскоп/тряска)
    ├── Info.plist                   # разрешения
    └── Assets.xcassets/             # иконка приложения, цвет акцента
```

## Публикация на свой GitHub

У меня нет доступа к интернету из этой среды, поэтому запушить сам я не
могу — но вот команды, которые сделают это за вас (выполните в папке
`CalculatorTrick`, из терминала на Mac):

```bash
cd CalculatorTrick
git init
git add .
git commit -m "Calculator trick iOS app"
git branch -M main
git remote add origin https://github.com/<ваш-логин>/<название-репозитория>.git
git push -u origin main
```

Репозиторий на GitHub нужно создать заранее (пустой, без README) —
на github.com кнопка **New repository**.
